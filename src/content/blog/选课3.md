这一篇用验收笔记的方式写。前两篇偏流程和代码，这一篇更像项目收尾时的检查清单：系统除了能选课，还要能录成绩、查成绩、管用户、看日志。一个教务系统做到这里，才更像完整项目。

## 验收一：教师可以录入成绩

教师端负责录入学生成绩。系统支持平时成绩、期中成绩、期末成绩，以及对应比例。

后端计算总评成绩的代码很直观：

```java
BigDecimal total = BigDecimal.ZERO;

if (grade.getUsualScore() != null && grade.getUsualRatio() != null) {
    total = total.add(grade.getUsualScore().multiply(grade.getUsualRatio()));
}
if (grade.getMidtermScore() != null && grade.getMidtermRatio() != null) {
    total = total.add(grade.getMidtermScore().multiply(grade.getMidtermRatio()));
}
if (grade.getFinalScore() != null && grade.getFinalRatio() != null) {
    total = total.add(grade.getFinalScore().multiply(grade.getFinalRatio()));
}

grade.setTotalScore(total.setScale(2, RoundingMode.HALF_UP));
```

这里使用 `BigDecimal`，比直接用浮点数更适合成绩、绩点这种需要精确计算的场景。

## 验收二：系统可以自动计算绩点

成绩录入后，系统会根据总评成绩计算绩点：

```java
private BigDecimal calculateGpa(BigDecimal score) {
    if (score == null) {
        return BigDecimal.ZERO;
    }
    double s = score.doubleValue();
    if (s >= 90) return BigDecimal.valueOf(4.0);
    if (s >= 85) return BigDecimal.valueOf(3.7);
    if (s >= 82) return BigDecimal.valueOf(3.3);
    if (s >= 78) return BigDecimal.valueOf(3.0);
    if (s >= 75) return BigDecimal.valueOf(2.7);
    if (s >= 72) return BigDecimal.valueOf(2.3);
    if (s >= 68) return BigDecimal.valueOf(2.0);
    if (s >= 64) return BigDecimal.valueOf(1.5);
    if (s >= 60) return BigDecimal.valueOf(1.0);
    return BigDecimal.ZERO;
}
```

学生端看到的不只是单科成绩，还包括学分、绩点、通过课程数量、班级排名和年级排名。这让成绩查询不只是展示表格，而是能帮助学生了解自己的学习情况。

## 验收三：成绩有提交、审核、发布流程

成绩不是教师录完就直接给学生看，而是经过状态流转：

```java
gradeMapper.update(null,
    new LambdaUpdateWrapper<StuGrade>()
        .eq(StuGrade::getOfferingId, offeringId)
        .eq(StuGrade::getGradeStatus, 1)
        .set(StuGrade::getGradeStatus, 2)
        .set(StuGrade::getSubmitTime, LocalDateTime.now())
);
```

成绩提交后进入待审核状态。教务管理员审核通过后，再发布给学生。

```java
gradeMapper.update(null,
    new LambdaUpdateWrapper<StuGrade>()
        .eq(StuGrade::getOfferingId, offeringId)
        .eq(StuGrade::getGradeStatus, 3)
        .set(StuGrade::getGradeStatus, 4)
        .set(StuGrade::getPublishTime, LocalDateTime.now())
);
```

这一点让系统更接近真实教务场景：教师负责录入，教务负责审核，学生负责查询。

## 验收四：管理员可以维护用户和权限

系统管理员端提供用户管理、角色管理和权限管理能力。用户管理主要解决账号维护问题，权限管理则决定不同角色能看到和操作哪些功能。

## 验收五：操作日志可以追踪问题

系统日志页面可以按用户、状态、日期范围筛选，还能查看请求地址、IP、耗时、错误信息。

![管理员操作日志查询](https://piv.cc.cd/file/BQACAgUAAyEGAASLVN5eAAJsZ2qgCQu4yDpjFiPF8uF_rG7rJi18AAJ_JAACnMUBVQOdG6kG4Mn8PQQ.jpg)

前端查询日志时会组装筛选条件：

```js
const params = {
  page: pagination.value.page,
  size: pagination.value.size
}

if (searchParams.value.username) {
  params.username = searchParams.value.username
}

if (searchParams.value.status !== null) {
  params.status = searchParams.value.status
}
```

这个功能对项目维护很有帮助。用户说“我刚才提交失败了”，管理员可以通过日志查看是谁、什么时候、访问了哪个接口、执行结果如何。
