这篇先不急着讲选课按钮，而是从系统入口开始。一个选课系统如果登录和权限没有搭稳，后面的学生选课、教师录入成绩、管理员管理用户都会变得很危险：页面能不能进、接口能不能调、用户是谁、操作有没有记录，这些都要先确定。

## 完成的功能

这个部分主要完成了四件事：

- 用户登录、注册、退出登录。
- 登录成功后返回 JWT，用于后续接口认证。
- 前端根据登录状态和角色进入不同页面。
- 使用操作日志记录登录、登出、修改密码等关键行为。

系统角色被拆成学生、教师、教务管理员、系统管理员。前端路由里也按角色分组：学生进入 `/student`，教师进入 `/teacher`，教务管理员进入 `/academic`，系统管理员进入 `/admin`。这样的好处是页面结构清楚，也方便后面继续扩展。

## 登录接口的核心代码

后端登录入口在 `AuthController` 中，控制器只负责接收参数、补充 IP、调用业务层，然后返回统一结果。

```java
@PostMapping("/login")
@OperationLog("用户登录")
public Result<LoginVO> login(@Valid @RequestBody LoginDTO loginDTO, HttpServletRequest request) {
    loginDTO.setIp(getClientIp(request));
    LoginVO loginVO = userService.login(loginDTO);
    return Result.success(loginVO);
}
```

这里我比较喜欢的一点是 `@OperationLog("用户登录")`。它没有把日志代码写进登录方法里，而是交给 AOP 自动处理。这样登录逻辑还是登录逻辑，日志逻辑也能独立维护。

## 前端请求如何带上 Token

前端通过 Axios 拦截器统一处理请求。只要用户已经登录，后续请求都会自动带上 `Authorization`。

```js
service.interceptors.request.use(config => {
  const userStore = useUserStore()
  if (userStore.token) {
    config.headers['Authorization'] = `Bearer ${userStore.token}`
  }
  return config
})
```

这样页面里调用接口时不用每次手动处理 token。比如查询课程、查询成绩、提交选课，写业务代码时只关心业务参数即可。

## 路由守卫的作用

前端路由守卫会判断当前页面是否公开页面。如果不是公开页面，就检查用户是否有 token。没有 token 时跳回登录页。

```js
router.beforeEach(async (to, from, next) => {
  const userStore = useUserStore()
  const token = userStore.token
  const publicPages = ['/login', '/register']

  if (publicPages.includes(to.path)) {
    next()
  } else {
    token ? next() : next('/login')
  }
})
```

这段逻辑让系统形成了一个基本闭环：未登录用户不能直接访问后台页面，登录用户刷新页面后也能继续恢复个人信息。

## 操作日志怎么自动记录

日志切面会读取请求地址、当前用户、执行方法、请求参数、执行耗时和异常信息。核心思想是：只要方法上标了 `@OperationLog`，系统就自动记录。

```java
@Around("logPointcut()")
public Object around(ProceedingJoinPoint point) throws Throwable {
    long startTime = System.currentTimeMillis();
    SysOperationLog operationLog = new SysOperationLog();

    try {
        Object result = point.proceed();
        operationLog.setExecTime((int) (System.currentTimeMillis() - startTime));
        operationLog.setStatus(1);
        saveLog(operationLog);
        return result;
    } catch (Throwable e) {
        operationLog.setStatus(0);
        operationLog.setErrorMsg(e.getMessage());
        saveLog(operationLog);
        throw e;
    }
}
```

## 这一部分的收获

登录和权限不是最显眼的功能，但它决定了系统能不能正常运转。选课系统后面所有功能都依赖这个入口：学生选自己的课，教师管理自己的课程，管理员查看用户和日志。先把身份确认、路由分流、请求认证和操作留痕做好，后面的业务才有一个可靠的地基。
